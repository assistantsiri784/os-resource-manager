## 1. Abstract
This project implements an educational simulation of operating-system resource-management algorithms using Python and Bash. It integrates CPU scheduling, memory allocation, deadlock analysis, disk scheduling, reporting, and automated tests in a single menu-driven workflow.

## 2. Problem Statement
Operating-system algorithms are often studied independently, making it difficult to compare their behavior using consistent inputs. This project provides one integrated environment for executing algorithms and examining their outcomes.

## 3. Objectives
- Implement CPU scheduling and calculate waiting, turnaround, and response times.
- Simulate First Fit, Best Fit, and Worst Fit memory allocation.
- Check safe states using Banker's algorithm and demonstrate deadlock detection.
- Compare disk scheduling using total head movement.
- Generate reproducible reports, charts, logs, and automated tests.
